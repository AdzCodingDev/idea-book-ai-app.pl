Data boundary

Local-first, not local-only.

Core idea persistence is designed around local Android storage. AI-assisted generation and telemetry have separate external-service boundaries, documented openly rather than hidden behind a vague “AI” label.

  • Idea libraryPrimary persistence uses a local Room / SQLite database on the Android device.
  • Gemini AIThe Android client includes direct Google Generative Language API integration for AI-assisted workflows.
  • FirebaseAnalytics, Crashlytics and Performance integrations are present in source; runtime/provider delivery is validated separately.
